## 🚀 核心原理与换区说明

当前最新版本的 TikTok 解锁机制已大幅简化。只要您的代理节点本身支援 TikTok ，就**不需要**再进行繁琐的 MitM 凭证安装和 URL 重写 (Rewrite)。

🌍 **关于地区切换**：
由于现在完全依赖节点本身来解锁，您在 TikTok 上看到的地区内容，将**直接取决于您所使用的节点 IP 所在国家/地区**。
- 想看 **日本区** TikTok 👉 请将策略切换至 **日本节点**
- 想看 **美国区** TikTok 👉 请切换至 **美国节点**
- 想看 **台湾区** TikTok 👉 请切换至 **台湾节点**

## ❓ 常见问题 (FAQ)

**Q1：为什么配置了分流还是无法观看，一直转圈圈、黑屏或提示「无网络连接」？**

A：这百分之百是因为**您的代理节点不支援 TikTok **（该节点 IP 已被 TikTok 官方封锁或识别为机房 IP）。请联络您的机场供应商确认是否支援 TikTok，或自行更换为「原生 IP」节点。

**Q2：我还需要像以前一样安装凭证并开启 HTTPS 解密 (MitM) 吗？**

A：**完全不需要！** 新方案直接依赖 App Store 最新版 + 支援的节点，免去了安装凭证、信任凭证和 URL 重写的步骤，更安全且不影响其他 App 运行。
